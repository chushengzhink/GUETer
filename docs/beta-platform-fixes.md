# Beta 平台修复与核心交互更新（2026-09-07）

本次修改基于 beta `f06a42e`，未合并到 main/master。

## 修复结果

- 畅课签到列表以动态响应读取，显式解析 JSON 并检查 HTTP 状态及列表结构。`text/plain` JSON 不再触发 String → Map 强制转换；HTML、空响应、服务错误与登录失效作为失败处理。
- 课堂派课程解析兼容数字/字符串状态码及 `data`、`data.list`、`data.lists`、`data.rows`、`data.data` 列表结构。错误向页面传递，失败不再伪装成零课程。
- 课堂派待签到列表补充 `data.lists`；依赖课程列表的查询沿用所选学期，并在请求链内固定账号和站点。
- 主课程页提供学期选择面板。选择按账号、服务器持久化；缓存、快照、搜索和滚动位置按学期隔离，旧请求不能覆盖新上下文。
- 刷新保留已有列表与位置，相同上下文共享进行中的请求；失败保留原有内容，显示重试或重新登录入口。
- 区分无课程、搜索无结果、加载失败和未登录。长 UID 单行省略，账号面板仍可查看完整标识。移除主课程页重复的扫码悬浮按钮。
- 畅课已结束活动不能进入签到流程，连续点击只打开一个页面；返回后刷新状态。页面继续使用现有主题并适配深色模式。
- 补齐课堂派课程详情、本地签到旧入口的错误处理与重试，避免错误传播后一直等待。待签到兼容入口不再吞掉异常；在线课程支持字符串状态码，并在请求开始时确定学期课程。
- 切回近期看过的学期仍会刷新，同时可以保留该学期的缓存内容；混合标记的畅课活动按实际进入的二维码方式显示。
- 主界面显示简短错误，请求控制台保留响应状态、格式、课堂派状态码与平台消息，供真实接口排查使用。

## 学期规则

月份计算只用于第一次预选，手动选择保存后优先使用保存值。

| 设备本地月份 | 学年（Y 为当年） | 学期 |
|---|---|---|
| 1 月 | Y−1—Y | 1 |
| 2—8 月 | Y−1—Y | 2 |
| 9—12 月 | Y—Y+1 | 1 |

例如 2026 年 9 月默认 `semester=2026-2027`、`term=1`。这不是学校校历；可在课堂派账号卡片下方选择学年与学期。取消不会更改列表。

旧的未区分学期课程快照不会用于新学期缓存，避免混入历史结果；其他平台快照格式不变。既有课程置顶与访问记录保留。

- master 的待签到解析已有 `data.lists`，beta 的遗漏已补齐。
