# 示例 Mod

这是一个安全的声明式 Mod 示例。它不会执行代码，也不会读取账号、Cookie、Token、OpenList 凭据或签到内部状态。

## 包含的入口

- `Mod 说明`：显示在工具页和命令搜索中，打开当前 Markdown 文件。
- `复制文件路径`：显示在文件预览页，仅匹配 PDF、文本、Markdown、JSON、CSV 和 ZIP。
- `保存文件备注`：把当前文件名写入插件私有目录，演示插件设置和写入能力。
- `打开健康中心`：显示在工具页、命令搜索和健康中心相关入口中。

## 使用方式

在 GUETer 的“插件管理”中导入此目录，扫描后启用 `示例 Mod`。启用后，对应入口会出现在声明的页面位置。
